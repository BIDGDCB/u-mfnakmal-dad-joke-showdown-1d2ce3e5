make.fun entry. `main.ts` (Node 22, standard library only) writes one
dad joke of at most 200 characters to `/output/entry.txt`, validating the
gate first.

Entry text:

> My lawnmower and I broke up — it just wasn't cutting it anymore.

Run it with `node main.ts`. See the bounty on
